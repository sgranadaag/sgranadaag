This is the user's own GitHub profile repository — `README.md` is the content that renders on their GitHub profile page (bio, tech stack, featured projects). It's a living document the user updates over time as their skills and experience grow, so treat it as the current, evolving source of truth for their background rather than a fixed snapshot.

## Workspace

When working in one of those other projects, this repo (and its README/CV) is the place to look for the user's overall background, skill set, and featured-project list.
